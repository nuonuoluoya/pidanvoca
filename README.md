# 随机单词本

一个简洁、有趣的浏览器英语词卡应用。将单词学习做成可翻动的卡片：随机抽取词条、按组推进学习，水浪会随着当前进度由卡片底部逐渐升高，并在完成时填满整张卡片。

`纯 HTML / CSS / JavaScript` · `无需安装依赖` · `支持离线使用` · `本地保存学习设置`

## 功能亮点

- **动态词卡**：3D 卡片堆叠与自然的左右切换动画，支持鼠标和键盘操作。
- **水浪进度**：波浪随当前学习组的进度升高，0% 时隐藏，100% 时填满卡片。
- **三种学习模式**：
  - 完整显示：展示单词、音标、释义和词形信息。
  - 只显示单词：隐藏音标、释义和时态等辅助信息。
  - 拼写练习：隐藏单词并显示横线输入框；拼写正确后以淡蓝色提示，并自动进入下一个单词；输入错误时停留在当前卡片。
- **自由控制学习量**：可选择每组 10、20、30、50 个、全部词条，或输入自定义数量。整轮结束前不会重复抽取。
- **内置发音**：通过浏览器的语音合成功能朗读当前单词。
- **词典查询**：一键前往 Cambridge Dictionary，并自动查询当前单词。
- **自定义词书**：一次导入一个或多个 HTML 生词本，自动合并重复单词，并可在设置面板中切换或删除。
- **记住上次选择**：使用 IndexedDB 保存导入的词书和当前选择；不可用时回退到 localStorage。
- **响应式与无障碍支持**：适配桌面和移动端，并尊重系统的“减少动态效果”设置。

项目内置 7 套词书，共 **20,319 张词卡**。该数字是各词书词条数之和，不代表跨词书去重后的单词总量。

| 词书         | 词条数 | 范围说明                                                     |
| ------------ | -----: | ------------------------------------------------------------ |
| 小学英语     |    502 | 《义务教育英语课程标准（2022年版）》二级词汇表               |

| 高考英语     |  2,999 | 普通高中英语课程标准的 3,000 词累计范围；合并原表形式后生成 2,999 张卡片 |
| 大学英语四级 |  4,114 | CET 考试大纲中未标“★”的四级词条                              |

| 考研英语     |  4,801 | 参考全国硕士研究生招生考试英语考试大纲，具体词条按 ECDICT `ky` 标签整理 |

词表范围主要参考[教育部课程标准](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)、[大学英语四、六级考试大纲](https://cet.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf)、[全国硕士研究生招生考试英语考试大纲](https://yankao.neea.edu.cn/xhtml1/report/21115/5092-1.htm)和[雅思官方备考说明](https://ielts.org/take-a-test/preparation-resources)。音标、中文释义及部分考试标签补充自 [ECDICT](https://github.com/skywind3000/ECDICT)。具体来源说明也保留在每个词书文件中。

## 快速开始

```bash
git clone https://github.com/nuonuoluoya/pidanvoca.git
cd pidanvoca
```

直接使用浏览器打开 `vocabulary-flashcards.html` 即可。应用不依赖服务器，也不需要执行 `npm install`。

也可以只下载 [`vocabulary-flashcards.html`](./vocabulary-flashcards.html)，它已经包含页面代码和全部内置词书。

## 使用方法

1. 打开页面，默认载入大学英语四级词书并随机排序。
2. 点击卡片两侧的图形按钮，或使用键盘切换单词。
3. 点击单词旁的模式按钮，依次切换“完整显示 → 只显示单词 → 拼写练习”。
4. 打开右上角设置面板，可切换词书、设置每组数量、重新随机或导入自己的生词本。
5. 完成当前组后，可以继续下一组、调整学习量，或在整轮结束后重新随机开始。

### 键盘快捷键

| 按键                    | 操作                     |
| ----------------------- | ------------------------ |
| `→` / `Space` / `Enter` | 下一个单词               |
| `←`                     | 上一个单词               |
| `R`                     | 重新随机排序             |
| `Esc`                   | 关闭设置面板或完成提示框 |

输入框获得焦点时，翻页快捷键不会打断拼写输入。

## 导入自己的词书

在“设置 → 导入生词本”中选择一个或多个 `.html` / `.htm` 文件。导入和解析均在浏览器本地完成，文件不会上传到服务器。

兼容的词书需要使用 HTML 表格，每行至少包含 5 个单元格：

| 列序号 | 内容                 |
| -----: | -------------------- |
|      1 | 编号，可留空         |
|      2 | 单词                 |
|      3 | 音标                 |
|      4 | 等级或分类，可留空   |
|      5 | 中文释义、词形或备注 |

导入成功后，词书会显示在“我的单词本”中，并在下次打开页面时自动恢复。浏览器隐私模式或被禁用的本地存储可能导致数据无法保留。

## 重新生成应用

如果修改了生成器或 `wordbooks/` 下的内置词书，请安装较新的 Node.js，然后运行：

```bash
node build-vocabulary.js
```

脚本会重新生成 `vocabulary-flashcards.html`。默认构建不会读取 `wordbooks/my/` 中的私人词书；日常使用私人词书时，建议直接通过页面导入，避免将个人数据写入并提交到生成文件。

## 项目结构

```text
.
├─ vocabulary-flashcards.html   # 可直接打开的完整应用
├─ build-vocabulary.js          # 页面与词书的生成脚本
└─ wordbooks/
   ├─ *-vocabulary.html         # 7 套内置词书源文件
   └─ my/                       # 本地私人词书目录，已被 Git 忽略
```

## 浏览器说明

- 推荐使用较新版本的 Chrome、Edge、Firefox 或 Safari。
- 单词发音依赖浏览器的 Web Speech API；不同系统可用的英文语音可能不同。
- Cambridge Dictionary 查询需要网络连接，其余核心词卡功能可在本地运行。
