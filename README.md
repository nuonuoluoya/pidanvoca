# 随机单词本（PidanVoca）

一个可离线使用的浏览器英语词卡应用。它把随机背词、分组学习、拼写练习和 FSRS 记忆曲线整合在同一套 3D 卡片界面中；学习数据默认只保存在当前浏览器，不需要账号或后端服务。

`HTML / CSS / JavaScript` · `在线按需加载` · `单文件离线版` · `本地保存进度` · `响应式布局`

## 在线使用

**[打开随机单词本 →](https://nuonuoluoya.github.io/pidanvoca/)**

## 当前功能

### 经典背词

- 3D 堆叠词卡与前后切换动画；桌面端可点击相邻卡片，移动端支持左右滑动。
- 水浪进度随当前学习组推进，完成整组时填满卡片。
- 三种学习模式：
  - **完整显示**：展示单词、音标、释义、词形和笔记。
  - **只显示单词**：隐藏音标、释义和词形信息。
  - **拼写练习**：隐藏英文单词，拼写正确后提示并自动进入下一词。
- 每组可选择 10、20、30、50、100、全部词条，或设置 5～500 的自定义数量；不同词书分别记忆设置。
- 支持浏览器语音朗读和 Cambridge Dictionary 查询。
- 提供默认的经典主题和可记忆选择的童趣主题。

### 单词本管理

- 内置 7 套词书，并在设置中统一归类为“内置”。
- 可一次导入一个或多个 `.html` / `.htm` 生词本；解析过程完全在浏览器本地完成。
- 导入后的词书显示在“我的单词本”中；没有自定义词书时该分组自动隐藏。
- 多文件导入时既保留各个词书，也提供去重合并后的临时学习视图。
- 支持删除“我的单词本”，并自动恢复上次选择的具体词书。
- 自定义词书、当前选择和删除记录优先保存到 IndexedDB；不可用时尝试回退到 localStorage。

页面通过构建时生成的 SHA-256 CSP 白名单限制内联脚本，禁用脚本属性、`eval`、对象和框架加载，并使用 `no-referrer`。卡片动画需要动态设置 CSS 变量，因此仅对样式属性保留 `style-src-attr` 权限；导入内容始终以文本渲染。

### FSRS 记忆曲线

- 使用 FSRS v6、90% 目标记忆率，为每个具体词书独立安排复习。
- 点击右上角记忆曲线图标后仍停留在当前页面，只将当前卡片切换为“今日复习”；再次点击或按 `Esc` 返回经典模式。
- 复习卡底部固定显示“忘记 / 查看答案 / 记得”三个按钮：
  - 回忆后可不查看答案，直接选择“忘记”或“记得”。
  - “查看答案”可在显示和收起之间切换，不影响普通回忆模式的评分。
  - 评分保存成功后，卡片沿经典模式的飞出轨迹离场，再显示下一词。
- 右上角可在“回忆模式”和“拼写练习”之间切换：
  - 拼写状态以中文词义为卡片主视觉，不显示“拼写这个单词”提示。
  - “忘记”始终可用，“记得”按钮及对应快捷键保持禁用。
  - 完整拼写正确后自动按“记得”评分，并进入下一词。
  - 拼写错误或主动查看答案后显示正确单词，本词只能按“忘记 / 继续”。
- 当前词书与日期不变时，再次进入可继续当日队列。
- 支持当前会话内连续撤销评分、每日新词设置、积压保护、JSON 进度备份与恢复。

### 响应式与无障碍

- 适配桌面和移动端布局，窄屏下保持主要按钮同排且不产生横向溢出。
- 使用语义化按钮、ARIA 状态、键盘操作和焦点管理。
- 尊重系统的“减少动态效果”设置。

## 快速开始

```bash
git clone https://github.com/nuonuoluoya/pidanvoca.git
cd pidanvoca
```

在线版入口是 `index.html`，会跳转到 `dist/web/index.html`。它启动时只携带默认词书，切换其他内置词书时根据 manifest 按需加载；Service Worker 按词库内容版本缓存资源，发现新版本时提示刷新但不会打断当前学习。本地开发时应通过静态服务器访问，以便浏览器正常请求 JSON 词库。

离线使用可只下载 [`vocabulary-flashcards.html`](./vocabulary-flashcards.html) 或 `dist/offline/vocabulary-flashcards.html`。两者都内嵌页面代码、FSRS 调度器和全部内置词书，可直接通过 `file://` 打开且不依赖 CDN。

## 使用方法

### 经典模式

1. 打开页面，默认载入大学英语四级词书并随机排序。
2. 使用卡片两侧按钮、桌面端相邻卡片或移动端滑动切换单词。
3. 点击单词旁的模式按钮，依次切换“完整显示 → 只显示单词 → 拼写练习”。
4. 打开右上角设置，可切换词书、设置每组数量、随机重排或导入自己的生词本。
5. 完成当前组后，可继续下一组、调整学习量，或在整轮结束后重新随机开始。

### 记忆曲线模式

1. 先在“单词本”中选择一个具体词书，再点击右上角记忆曲线图标。
2. 回想词义后可直接评分，也可点击中间按钮查看答案。
3. 如需练习拼写，点击复习卡右上角的模式图标；输入完整正确拼写后会自动评分和切换。
4. 使用右上角撤销按钮或 `Ctrl/Cmd + Z` 可依次撤销当前会话中的最近评分。
5. 再次点击记忆曲线图标、复习卡关闭按钮或按 `Esc` 返回经典模式。

## 键盘快捷键

### 经典模式

| 按键                    | 操作                   |
| ----------------------- | ---------------------- |
| `→` / `Space` / `Enter` | 下一个单词             |
| `←`                     | 上一个单词             |
| `R`                     | 重新随机排序           |
| `Esc`                   | 关闭设置或学习完成提示 |

### 记忆曲线模式

| 按键           | 操作                         |
| -------------- | ---------------------------- |
| `Space`        | 显示答案                     |
| `1` / `←`      | 选择“忘记”                   |
| `2` / `→`      | 选择“记得”（仅回忆模式）     |
| `Ctrl/Cmd + Z` | 撤销最近一次评分，可连续使用 |
| `Esc`          | 返回经典模式                 |

输入框获得焦点时，全局翻页和评分快捷键不会打断拼写输入。记忆曲线拼写练习中，输入正确答案会自动提交；按 `Enter` 可提交错误答案并查看正确单词。

## 记忆曲线与本地进度

- 每个具体词书独立记录 FSRS 卡片状态；多文件合并产生的临时视图不会建立记忆曲线记录。
- 默认每日加入 10 个新词；到期积压达到 50 张时暂停加入新词。
- “忘记”使用 10 分钟学习/重学步骤；“记得”的下次间隔由 FSRS 动态计算并显示在按钮上。
- 到期卡优先于新词；同一天的新词选择保持稳定。
- 设置中的“记忆曲线”可调整每日新词数量，并导出、合并导入、替换导入或重置进度。
- 复习卡片、日志和记忆曲线设置写入 IndexedDB。瞬时错误会有限重试；IndexedDB 仍不可用时，只有在用户明确确认后才进入临时会话，页面刷新后进度不会保留。
- 重置操作不会删除词书内容；执行前建议先导出 JSON 备份。

## 导入自己的词书

在“设置 → 导入生词本”中选择一个或多个 `.html` / `.htm` 文件。文件只在浏览器本地读取，不会上传到服务器。

兼容的词书使用 HTML 表格，每行至少包含以下 5 个单元格：

| 列序号 | 内容                 |
| -----: | -------------------- |
|      1 | 编号，可留空         |
|      2 | 单词                 |
|      3 | 音标                 |
|      4 | 等级或分类，可留空   |
|      5 | 中文释义、词形或备注 |

同一次多文件导入会按不区分大小写的单词键去重；重复词条会尽量保留音标，并合并不同的释义和笔记。读取前会限制文件类型、数量（最多 20 个）、单文件大小（10 MB）和总大小（50 MB）；DOM 提取保留在主线程分批执行，字段校验与合并由可取消 Worker 完成。浏览器隐私模式、存储空间不足或禁用本地存储可能导致导入结果无法长期保留。

## 开发、测试与构建

开发环境需要 Node.js 20 或更高版本。项目包含锁文件，推荐使用：

```bash
npm ci
npm run check
npm run test:e2e
npm run perf:check
```

- `npm run check`：依次运行 ESLint、格式检查、JavaScript 类型检查、Node 测试和可复现构建。
- `npm run test:e2e`：在桌面和移动端 Chromium 中验证经典模式、记忆模式、设置、导入、动画、在线按需加载及 `file://` 离线启动。
- `npm run perf:check`：检查在线/离线产物体积，并以固定数据验证 20,000 词洗牌与 50,000 词导入合并没有明显性能退化；预算记录在 `performance-budgets.json`。
- `npm run build`：从同一套源码生成 `dist/web/index.html` 在线壳、`data/books.manifest.json` 与 JSON 词库、`dist/offline/vocabulary-flashcards.html`，并同步根目录离线文件。
- 默认构建不会读取 `wordbooks/my/`，避免将私人词书写入生成文件。
- 如确实需要把 `wordbooks/my/` 中的 HTML 词书嵌入构建结果，可在构建进程中设置 `INCLUDE_PERSONAL_WORDBOOKS=1`。生成文件将包含私人数据，提交或分享前请检查内容。

## 浏览器说明

- 推荐使用较新版本的 Chrome、Edge、Firefox 或 Safari。
- 单词发音依赖 Web Speech API；可用英文语音因浏览器和操作系统而异。
- Cambridge Dictionary 查询需要网络连接，其余核心学习功能可离线运行。
- 直接通过 `file://` 打开时，不同浏览器对 IndexedDB 的支持策略可能不同；若本地进度无法保存，可使用本地静态服务器打开页面。
